# xcs_to_bpp_batch.py 使用說明

## 目的
將 CNC 加工描述檔（.xcs）批次轉換為 Biesse 機台可用的 .bpp 加工程式檔案，並自動對應加工面、基準點、加工型態等欄位。

---

## 功能特色
- 支援整個資料夾內所有 .xcs 檔案自動轉換為 .bpp 檔案。
- 解析 xcs 檔案中的工件尺寸、基準點、加工面、鑽孔資訊。
- 自動產生 BPP 標準檔案結構。
- 加工面、基準點自動對應。
- 根據加工面自動切換垂直/水平加工。
- 每個孔自動產生唯一8碼識別碼（時間+流水號）。

---

## 使用方式
1. 將 `xcs_to_bpp_batch.py` 放在含有 .xcs 檔案的資料夾內。
2. 執行 `python xcs_to_bpp_batch.py`。
3. 選擇來源與輸出資料夾，程式自動批次轉換。

---

## 支援的 xcs 指令
- `CreateFinishedWorkpieceBox`
- `SetWorkpieceSetupPosition(a,b,c,d)`
- `SelectWorkplane("Top"/"Left"/… )`
- `CreateDrill(...)`

---

## 詳細轉換規則

### 1. 檔案命名規則
- 檔名以 SP 開頭（不分大小寫）時，視為 SP 規則（is_sp = True）。

### 2. 工件尺寸（LPX、LPY、LPZ）
- 由 `CreateFinishedWorkpieceBox` 取得。
- 若為 SP 規則，LPX、LPY 各自減 1。

### 3. CreateDrill 參數對應
- 來源 xcs 參數順序：x, y, 深度, 直徑
- 轉出 bpp 參數順序：x, y, 深度, 直徑

### 4. 點孔與穿孔規則
- 點孔：直徑8、深度2，bpp 直徑改為8.2。
- 穿孔：直徑8、深度26，bpp 直徑改為8.1，深度改為18.5。

### 5. SP 規則下 TOP 面孔位
- 若為 SP 規則且 current_workplane == 0（TOP 面），x、y 各自減 0.5。

### 6. 鑽孔工具與旗標
- 直徑為 26 時，tool 設為 2，flag 設為 1。
- 直徑為 2 時，tool 設為 2，flag 設為 0。
- 其他情況 tool 設為 12，flag 設為 0。

### 7. 鑽孔加工型態
- current_workplane 為 1, 2, 3, 4（側面）時，op_type 設為 BH。
- 其他（如 TOP、BOTTOM）op_type 設為 BV。

### 8. 基準點對應
- 0,0,0,0 → 2（左下）
- 0,1,0,0 → 1（左上）
- 1,0,0,0 → 3（右下）
- 1,1,0,0 → 4（右上）

### 9. 唯一碼
- 每孔自動產生時間+流水號（如16100001）。

### 10. 其他
- 其餘參數與標籤依照固定格式組成 bpp 行。
- 批次轉換所有 .xcs 檔案，輸出為 .bpp 檔案。
